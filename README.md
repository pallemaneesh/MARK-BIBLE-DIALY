# Bible Attendance Tracker ✝

A beautiful, role-based web application for tracking daily Bible study attendance. Designed for **Enosh** (Brother) to mark his devotion and **Titus** (Admin) to monitor progress.

## Features ✨

- **Dual Roles:** Dedicated interfaces for Brother (devotion marking) and Admin (overview & logs).
- **Parchment UI:** A thematic, visually appealing design with "Bible-style" aesthetics.
- **Firebase Integration:** Real-time data persistence and sync across devices.
- **Email Notifications:** Automatic alerts sent via EmailJS when attendance is marked.
- **Browser Notifications:** Push notifications for real-time alerts.
- **Attendance Stats:** Track monthly records, streaks, and total days.
- **Interactive Calendar:** View past verses and notes with a tap.

## Setup 🚀

1.  **Firebase:** The app is pre-configured with a Firebase project. Ensure Firestore rules allow read/write access for the `attendance` collection.
2.  **EmailJS:** Integrated to send notifications to `maneeshtity1@gmail.com`.
3.  **Deployment:** Simply host the `index.html` file on any static web host (GitHub Pages, Netlify, Vercel, etc.).
